美国时区实时对照网站

文件：index.html

使用方法：
1. 解压网站压缩包。
2. 双击打开 index.html，即可在现代浏览器中使用。
3. 也可以把 index.html 上传到 GitHub Pages、Cloudflare Pages 或自己的静态网站空间。

功能：
- 显示美国九大法定时区的实时当地时间、日期、缩写与 UTC 时差。
- 自动根据 IANA 时区规则适配夏令时。
- 以 24 小时进度条比较各地当前时刻，并区分白天/夜间。
- 支持按美国本土、阿拉斯加/夏威夷、海外属地筛选，以及城市/时区关键词搜索。
- 单文件实现，无需安装依赖或配置服务器。

说明：
页面时间由访问者设备浏览器计算。若设备系统时间不准确，页面显示也可能有偏差。
